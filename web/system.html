Update

Auto-update is disabled on this instance. To update manually, run on the server:

cd /opt/vpscontrol-src && git pull && go build -o /usr/local/bin/vpscontrol . && systemctl restart vpscontrol

You can also configure a GitHub webhook below to trigger updates on push.

GitHub webhook

Add a webhook on the repo (Settings → Webhooks → Add webhook) so every push to GitHub triggers an update here. Content type: application/json · Events: Just the push event.
