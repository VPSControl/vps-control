Connect your GitHub account

Link a GitHub Personal Access Token to import private repositories and repositories from your organisations. You'll be able to deploy them directly from the panel.

How to create a token:

  1. Go to github.com/settings/tokens/new
  2. Give it a name (e.g. VPS Control)
  3. Select the repo scope (full control of private repositories)
  4. If you need organisation repos, add read:org
  5. Click Generate token and copy it
